# 프로젝트 소개

## 한 줄 소개

**피치메이트**는 발표 영상을 음성, 자세, 표정, 시선 처리, 제스처 데이터로 분석하고 실천 가능한 한국어 코칭 리포트를 제공하는 서비스다. 개발 팀명은 **MULMOCO**다.

## 해결하려는 문제

발표자는 녹화 영상을 다시 보더라도 말하기 속도, 불필요 표현, 침묵, 시선 이탈, 자세와 손동작을 일관된 기준으로 판단하기 어렵다. 피치메이트는 실제 영상과 음성에서 계산한 정량 지표, 감지 신뢰도, 타임스탬프 관찰, 한국어 개선 행동을 하나의 리포트로 제공한다.

## 구현된 핵심 기능

- 이메일 회원가입·로그인, JWT access token, HttpOnly refresh cookie
- 사용자 소유권 검증과 관리자 역할 분리
- 최대 500MB 업로드, 진행률, 업로드 취소, 자동 분석 시작
- 비동기 상태 조회, 분석 취소, 실패·취소 작업의 동일 `jobId` 재분석
- backend 재시작 시 진행 중 작업 복구
- MediaPipe/OpenCV, faster-whisper 기반 정량 분석
- NVIDIA Nemotron 관찰, Ollama `qwen3-vl:4b` fallback
- Ollama `qwen3:4b` 한국어 최종 피드백과 결정적 fallback
- 리포트 목록·상세·삭제, 영상 streaming, 신뢰도 경고
- Flyway, 백업·복원, Rate Limit, CI

## 점수와 LLM 역할

종합 점수는 자세 25%, 표정 20%, 시선 처리 20%, 음성 25%, 제스처 10%다. 논리 구조는 피드백에만 사용한다. Nemotron과 Text LLM은 관찰과 설명을 만들지만 정량 점수를 새로 계산하거나 덮어쓰지 않는다.

## 미구현·제한

- 실제 OpenAI provider 호출
- 브라우저 E2E 자동화
- Redis 기반 분산 Rate Limit
- 사용자별 동시 분석 제한과 idempotency key
- 실제 서버 로그를 저장·조회하는 관리자 로그 기능
- 실제 분석 엔진 health를 반영하는 관리자 health

## 심사위원 설명 포인트

핵심은 AI 호출 하나가 아니라 인증, 파일 수명주기, 비동기 상태, 취소·재시도, 신뢰도 기반 점수, fallback, 결과 보관, 복구와 운영 절차까지 연결했다는 점이다. 정량 분석과 생성형 AI의 역할을 분리해 LLM 표현의 변동이 평가 점수를 임의로 바꾸지 않도록 했다.
