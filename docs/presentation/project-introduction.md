# 프로젝트 소개

## 한 줄 소개

Presentation Coaching AI는 발표 영상을 업로드하면 음성, 자세, 시선, 표정, 제스처 지표를 분석하고 사용자가 다시 볼 수 있는 코칭 리포트를 생성하는 서비스이다.

## 해결하려는 문제

발표 연습은 스스로 녹화해도 어떤 부분을 고쳐야 하는지 객관적으로 판단하기 어렵다. 이 프로젝트는 발표 영상을 구조화된 지표와 타임라인 피드백으로 변환해 사용자가 반복 연습할 수 있게 한다.

## 현재 구현된 핵심 기능

- 이메일/비밀번호 회원가입과 로그인
- JWT access token과 httpOnly refresh token 기반 인증
- 사용자별 영상 업로드와 소유권 검증
- 분석 작업 생성, 진행 상태 조회, 실패 재시도
- analysis-engine 기반 점수 계산
- video-llm-engine 기반 샘플 프레임 관찰 피드백
- 결과 보관함, 결과 상세, 영상 스트리밍
- `ADMIN`/`MANAGER` 운영 콘솔
- `ADMIN` 사용자 권한 변경과 추방

## 현재 미구현 또는 추가 예정

- Text LLM 최종 피드백 생성
- OpenAI API 호출
- 실제 손 랜드마크 기반 제스처 분석
- 무음 구간의 실제 VAD 기반 탐지
- 운영 콘솔 시스템 로그의 DB 저장. 현재는 프론트 mock 상수
- 분석 취소 API. `CANCELED` enum만 존재

## 심사위원 설명 포인트

이 프로젝트는 AI 모델 자체만 보여주는 데서 끝나지 않고, 업로드, 인증, 상태 관리, 재시도, 결과 저장, 운영 화면까지 포함한 서비스 흐름을 구현했다. 특히 분석 작업은 비동기로 실행되고, 실패한 작업은 같은 `jobId`로 다시 실행할 수 있다.
