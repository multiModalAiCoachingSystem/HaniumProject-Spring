# 발표 영상 촬영 가이드

## 목적

피치메이트의 얼굴, 시선, 자세, 제스처 분석은 영상에서 보이는 랜드마크 품질에 영향을 받는다. 아래 조건은 점수를 높이기 위한 요령이 아니라 분석 신뢰도를 확보하기 위한 촬영 기준이다.

## 권장 조건

- 얼굴이 프레임에서 너무 작지 않게 촬영한다.
- 정면 또는 정면에 가까운 각도를 유지한다.
- 이마, 눈, 입, 턱이 화면 밖으로 잘리지 않게 한다.
- 얼굴에 강한 역광이나 그림자가 생기지 않도록 밝은 곳에서 촬영한다.
- 어깨부터 양손까지 보이도록 상반신 구도를 잡는다.
- 카메라는 흔들리지 않게 고정한다.
- 세로 영상도 회전 metadata를 반영해 처리하지만, 상반신과 양손 확보를 위해 가로 촬영을 권장한다.
- 발표대나 물체가 팔과 손목을 지속적으로 가리지 않게 한다.
- 목소리가 배경음보다 충분히 크게 녹음되도록 마이크와 거리를 조정한다.

## 분석 신뢰도가 낮아지는 경우

| 상황 | 주로 영향받는 항목 |
|---|---|
| 얼굴이 작거나 측면인 영상 | 표정, 시선 처리 |
| 얼굴이 잘리거나 가려짐 | 표정, 시선 처리 |
| 손과 팔이 화면 밖에 있음 | 제스처 |
| 카메라 흔들림 | 자세, 제스처 |
| 어두움·역광 | 얼굴 landmark 전반 |
| 배경 소음·매우 작은 음량 | 침묵, 음량 안정성, STT |

감지 신뢰도가 낮으면 결과 화면에 사용자 친화적인 경고가 표시된다. 상세 수치는 “상세 분석 지표 보기”에서 확인할 수 있다.

## 현재 한계

작은 측면 얼굴에 대한 FaceMesh/Haar crop retry는 개선되었지만 모든 환경을 보장하지 않는다. 더 강한 detector, MediaPipe Tasks Face Landmarker, 촬영 품질 사전 경고는 장기 개선 항목이다.
