# 사용자 가이드

## 1. 계정과 로그인

회원가입 후 이메일과 비밀번호로 로그인한다. 로그인 상태에서만 영상, 분석 작업, 리포트에 접근할 수 있으며 다른 사용자의 데이터는 조회·취소·재시도·삭제할 수 없다.

## 2. 영상 업로드와 분석

1. **분석 시작**에서 영상을 선택한다.
2. 파일명, 크기, 촬영 상태를 확인한다.
3. **업로드 및 분석 시작**을 누른다.
4. 업로드가 완료되면 서버가 분석 job을 만들고 자동으로 분석을 시작한다.

지원 형식은 MP4, MOV, AVI, MKV, WEBM이며 최대 크기는 500MB다. 촬영 전에는 [촬영 가이드](shooting-guide.md)를 확인한다.

업로드 중 **업로드 취소**는 아직 job이 없는 HTTP 요청만 중단한다. 선택 파일은 유지되어 다시 업로드할 수 있다.

## 3. 분석 상태

| 표시 | 서버 상태 | 가능한 동작 |
|---|---|---|
| 분석 대기 | `QUEUED` | 분석 중단 |
| 분석 중 | `PROCESSING` | 분석 중단 |
| 취소 처리 중 | `CANCEL_REQUESTED` | 완료까지 상태 조회 |
| 취소됨 | `CANCELED` | 같은 job 재분석, 삭제 |
| 완료 | `DONE` | 결과 보기, 삭제 |
| 실패 | `FAILED` | 같은 job 재시도, 삭제 |

페이지를 이동했다 돌아와도 저장된 job ID와 서버 상태 조회를 기준으로 화면이 복구된다. 진행 상태는 4초 간격으로 조회하며 완료·실패·취소 상태에서는 polling을 중단한다.

## 4. 취소와 재분석

`QUEUED`는 즉시 `CANCELED`가 된다. 이미 외부 엔진 호출 중인 `PROCESSING`은 `CANCEL_REQUESTED`가 된 뒤 현재 호출이 반환되는 확인 지점에서 `CANCELED`로 확정된다.

`FAILED`와 `CANCELED`는 원본 영상이 있을 때 동일한 `jobId`로 재분석한다. 이전 결과와 부분 산출물을 정리한 후 `QUEUED`부터 다시 계산한다. 원본이 없으면 새 영상을 업로드해야 한다.

## 5. 리포트

보관함은 최신 등록순을 기본으로 완료, 실패, 취소, 진행 중 작업을 보여준다.

- 완료 리포트: 종합 점수와 자세·표정·시선 처리·음성·제스처 점수
- 신뢰도 경고: 얼굴 또는 팔 감지 품질이 낮은 경우 표시
- 강점/개선 필요: observation의 `level`로 분류된 한국어 카드
- 상세 분석 지표: 기본 접힘, 사용자가 펼칠 때만 raw metric 표시
- 대본과 예상 질문: 분석 가능 데이터가 있을 때 표시

Video LLM 관찰은 설명과 타임스탬프 피드백에 사용되며 정량 점수를 직접 변경하지 않는다.

## 6. 삭제

`DONE`, `FAILED`, `CANCELED`만 삭제할 수 있다. 삭제하면 job과 결과 DB 데이터, 더 이상 다른 job이 참조하지 않는 원본, 변환본, 썸네일, 임시 산출물을 정리한다. `QUEUED`, `PROCESSING`, `CANCEL_REQUESTED`는 삭제할 수 없다.
